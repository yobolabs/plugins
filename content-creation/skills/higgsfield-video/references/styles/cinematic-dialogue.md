# Style: cinematic dialogue (scenes, characters, acting)

Back to [SKILL.md](../../SKILL.md). Status: **stub — from Higgsfield's own creator tutorial, not proven here.**

## Their workflow

- One project folder per scene, with Characters / Locations / Props. Every asset saved as a named **element**;
  the same names are used in prompts so the right references attach (`@char_name_v1`, `@loc_room_v1`, `@prop_x`).
- Characters: a model sheet, then cleaned with reference shots for hair, skin pores and fabric so they don't
  look plastic. Video elements (with recorded voice) for how they move and sound.
- Lenses: 24 mm anamorphic for wide environments, 35 mm for tighter frames; three-quarter views for depth.
- Prompt: ACTIVE REFERENCES (each element + what it controls, e.g. "defines what the door looks like — it does
  not dictate camera position or framing"), SCENE CONTEXT (the intent, prose), OPTICS (field of view per shot,
  "keep the lens fixed within each shot"), CAMERA, ACTION TIMING (second by second), LIGHTING · SOUND · STYLE.
- Acting: write each character's intent (what they want from the other person); give dialogue time.
- Drafts at 480p; batch takes; cut on movement; overlap the last line of the previous take for an edit handle.
- Blocking reference: an overhead frame with marked start positions when the model confuses who stands where.

## Proven here (storyboards)

- Masters per camera setup, every other shot an edit of its master (`references-and-sheets.md`): stable faces,
  seats and rooms across a part's shots.
- Write the dialogue as a track by time and speaker; off-screen voices carry across cuts.
